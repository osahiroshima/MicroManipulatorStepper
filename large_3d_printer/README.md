# 大型3Dプリンター計画（ST-42BYH1004-5013 モーター活用）

> マイクロマニピュレーターには長すぎて使えなかった NEMA17 モーター **ST-42BYH1004-5013（0.9°、本体長48mm）** を、
> 大型 3D プリンターに転用するための計画書です。**💡 解説** で考え方や用語を補足しています。

---

## 1. 目標仕様（たたき台）

| 項目 | 目標 | 備考 |
|---|---|---|
| 造形サイズ | **350 × 350 × 350 mm** | 一般的な家庭用（220〜250mm）より一回り大きい |
| 方式 | **CoreXY ＋ ベッド昇降（Z 3本）** | Voron Trident と同じ構成 |
| 印刷速度 | 実用 **80〜120 mm/s**、移動 最大 150 mm/s | モーター特性からの上限（§3） |
| 加速度 | 3,000 mm/s² 前後 | インプットシェーパー調整後に決める |
| 電源 | **24V** DC（モーター・ホットエンド）＋ 100V AC（ヒートベッド） | |
| ファームウェア | **Klipper** | Raspberry Pi ＋ 制御ボード |
| 使うモーター | ST-42BYH1004-5013 × **5台**（X/Y 用 2 ＋ Z 用 3） | エクストルーダーは別の小型モーター |

### 💡 解説

- **CoreXY**：X と Y の 2 つのモーターを本体フレームに固定し、2 本のベルトの組み合わせでヘッドを XY に動かす方式です。モーターが動かないので可動部が軽く、大型でも速く・正確に動かせます。
- **ベッド昇降（Z 3本）**：ベッドが上下に動き、3 本のネジ（リードスクリュー）で支えます。3 点で支えると「面」が一意に決まるので、Klipper の `Z_TILT_ADJUST` でベッドの傾きを自動補正できます。
- **なぜベッドを前後に動かす方式（Ender 3 などの方式）にしないのか**：350mm 角のベッドは重く（1.5〜2kg 以上）、それを前後に振り回すと振動が大きくなり、速度も出ません。大型ではベッドを XY に動かさない方式が定番です。

## 2. このモーターの評価

| 項目 | 値 | 3D プリンター用途としての評価 |
|---|---|---|
| 保持トルク | 0.43 N·m（4.4 kgf·cm） | ✅ 一般的な 3D プリンター用モーターと同等 |
| ステップ角 | 0.9°（400 ステップ/回転） | ✅ 位置の細かさは 1.8° の 2 倍。表面がきれいになりやすい |
| 定格電流 | 1.0 A/相 | ✅ TMC2209 で十分駆動できる |
| 巻線抵抗 | 5.0 Ω | △ 抵抗が高め |
| インダクタンス | 11.5 mH | ⚠️ **かなり高い** → 高速回転が苦手 |
| 本体長さ・重さ | 48mm・340g | ✅ フレーム固定の CoreXY なら問題なし |

### 💡 解説

- **インダクタンスが高いと何が困る？**
  コイルは電流の変化を嫌う性質（インダクタンス）を持っています。モーターが速く回るほど、コイルの電流を速く切り替えなければなりませんが、インダクタンスが高いと切り替えが間に合わず、**電流＝トルクが足りなくなります**。さらに、回転すると発電機のように逆向きの電圧（逆起電力）も生まれます。
  この 2 つに打ち勝つには **電源電圧を高くする** 必要があります。マイクロマニピュレーターは非常にゆっくり動くので 5V で十分でしたが、3D プリンターでは 24V 以上が必須です。
- **0.9° モーターの長所と短所**：1 回転が 400 ステップなので位置が細かく、表面の細かい縞模様（ステップ由来の模様）が出にくいのが長所です。一方、同じ移動速度でも 1.8° モーターの 2 倍の周波数で電流を切り替える必要があるため、高速では不利になります。

## 3. 速度の見積もり（重要）

[`tools/motor_speed_estimate.py`](tools/motor_speed_estimate.py) で、データシートの値から「トルクが落ち始める速度」を概算しました（GT2 ベルト＋20 歯プーリー＝1 回転 40mm）。

| 電源 | 電流 0.6A | 電流 0.8A | 電流 1.0A |
|---|---|---|---|
| 5V | 21 mm/s | 11 mm/s | 0 mm/s |
| 12V | 79 mm/s | 61 mm/s | 48 mm/s |
| **24V** | 174 mm/s | **138 mm/s** | 113 mm/s |
| 36V | 269 mm/s | 214 mm/s | 176 mm/s |
| 48V | 363 mm/s | 289 mm/s | 239 mm/s |

**結論：24V・0.8A で約 140 mm/s がトルクを保てる上限の目安。** 実機は共振などでこれより下がることが多いので、印刷は 80〜120 mm/s を想定します。
もっと速くしたくなった場合は、48V 対応ドライバー（TMC5160 など）に替えると 2 倍程度まで伸ばせます。

### 💡 解説

- **5V では使えない**：表のとおり、マイクロマニピュレーターの電子回路（5V・TB6612FNG）のままでは毎秒 1〜2cm しか動けません。**3D プリンターには専用の制御ボードとドライバーを使います。**
- **この計算は目安です**：逆起電力定数を「保持トルク ÷ 定格電流」で近似するなど、単純化したモデルです。最終的には実機で速度を上げていき、脱調（ステップ抜け）しない速度を確かめます。
- **電流を下げると速く回せる理由**：流す電流が小さいほど、電流を切り替えるのに必要な電圧が小さくて済むからです。そのぶん保持トルクは下がるので、0.8A 程度がバランスの良い値です。

## 4. 全体構成

```
                ┌──────────────── 100V AC ────────────────┐
                │                                          │
        ┌───────▼──────┐                           ┌───────▼──────┐
        │ 24V 電源      │                           │ SSR（半導体   │
        │ (350W 程度)   │                           │  リレー)      │
        └───┬──────────┘                           └───────┬──────┘
            │                                              │
   ┌────────▼─────────────────┐                    ┌───────▼──────────┐
   │ 制御ボード (BTT Octopus)  │── SSR 制御信号 ──▶ │ ヒートベッド      │
   │  TMC2209 × 6              │                    │ (AC シリコンヒーター)│
   │  X, Y, Z×3, E             │                    └──────────────────┘
   └───┬───────────┬──────────┘
       │ USB        │ モーター・ヒーター・センサー
┌──────▼──────┐   ▼
│ Raspberry Pi │  ST-42BYH1004 ×5（X, Y, Z1, Z2, Z3）
│ (Klipper)    │  エクストルーダー用 小型モーター ×1
│  Mainsail    │  ホットエンド、ファン、サーミスタ、エンドストップ、ベッドプローブ
└─────────────┘
```

### 💡 解説

- **Klipper**：重い計算（経路計画など）を Raspberry Pi が行い、制御ボードは「決められたタイミングでパルスを出す」だけに専念する方式のファームウェアです。マイクロマニピュレーターのファームウェアが 1 台の Pico で行っていたことを、2 台に分担するイメージです。
- **Mainsail**：Klipper をブラウザから操作するための画面です。
- **TMC2209**：静かで、**電流を一定に保つ（定電流チョッパー）** ドライバーです。電源電圧が 24V でも、モーターには設定した電流（例：0.8A）しか流れないので焼けません。マイクロマニピュレーターの TB6612FNG は電流を制御しないため、電圧を上げられなかったのとは対照的です。
- **SSR とヒートベッド**：350mm 角のベッドを 24V で温めると電流が大きすぎるので、100V AC のシリコンヒーターを SSR（スイッチ役の部品）で ON/OFF します。**AC 100V を扱うので §8 の安全対策を必ず守ってください。**

## 5. 各軸の設計

### X / Y 軸（CoreXY）
- モーター：ST-42BYH1004 × 2（フレーム後方に固定）
- ベルト：GT2 **9mm 幅**（大型なので 6mm より伸びにくい幅広を選ぶ）
- プーリー：GT2 20 歯（1 回転 = 40mm）
- レール：MGN12 リニアガイド（X は 1 本、Y は左右 2 本）
- 分解能：40mm ÷ (400 × 16 マイクロステップ) = **約 6.3 µm/マイクロステップ**

### Z 軸（ベッド昇降・3 点支持）
- モーター：ST-42BYH1004 × 3
- 送りネジ：**T8 リード 2mm**（1 回転で 2mm 上下）
  - 2mm リードはモーターを止めてもベッドが自重で落ちにくく、分解能も高い（約 0.3 µm/マイクロステップ）
  - 速度は遅め（最大 10〜15 mm/s）ですが、Z はほとんど動かないので問題ありません
- ガイド：MGN9 または MGN12 リニアガイド（各支点の横）
- `Z_TILT_ADJUST` で 3 本の高さを自動で揃える

### エクストルーダー
- **このモーターは使わない**（340g は重すぎてヘッドが重くなり、速度と画質が落ちる）
- 小型の「パンケーキ型」モーター（本体長 20〜25mm）＋ ギア減速式ダイレクトエクストルーダー（例：Orbiter、Sherpa Mini、Clockwork 2 など）

### 💡 解説

- **マイクロステップ**：ドライバーが電流を細かく調整し、1 ステップをさらに 16 分割などに細分化する機能です。これはマイクロマニピュレーターで PWM を使って「ステップの間」で止めていたのと同じ考え方です。
- **ベルト幅**：ベルトはゴムなので少し伸びます。長いベルトほど伸びの影響が大きいので、大型機では太いベルトで剛性を上げます。
- **ダイレクトエクストルーダー**：フィラメントを押し出すモーターをヘッドの上に載せる方式です。柔らかいフィラメント（TPU など）も扱いやすい反面、ヘッドが重くなるので軽いモーターを選びます。

## 6. マイクロマニピュレーターから応用できること

| マイクロマニピュレーターの技術 | 大型プリンターでの使い道 |
|---|---|
| 0.9° モーターの細かさ | X/Y の表面品質向上（そのまま活かせる） |
| Raspberry Pi Pico | **加速度センサー（ADXL345）用の USB アダプター** にして、Klipper のインプットシェーパー測定に使える |
| 磁気エンコーダー（MT6835）とクローズドループ制御 | 発展課題：X/Y モーターにエンコーダーを付けて **脱調（ステップ抜け）を検出** する実験（§9 フェーズ 4） |
| パラレルリンク（デルタ）の運動学 | 将来の別案：大型デルタ型プリンター（今回は調整が簡単な CoreXY を優先） |
| G-Code の知識 | Klipper も G-Code で動くので、そのまま使える |

### 💡 解説

- **インプットシェーパー**：ヘッドを動かしたときに起きる揺れ（共振）を加速度センサーで測り、その揺れを打ち消すように動きを補正する Klipper の機能です。大型機は揺れやすいので、ほぼ必須の機能です。
- **脱調検出**：一般的な 3D プリンターはオープンループなので、ヘッドが何かにぶつかって位置がずれても気付けません。マイクロマニピュレーターのようにエンコーダーで実際の角度を測れば、ずれを検出して印刷を止めることができます（Klipper 標準機能ではないので研究課題）。

## 7. 参考にするオープンソース設計

ゼロから設計するより、**実績のある設計をベースにして、このモーター用に設定を合わせる**のが近道です。

- **Voron Trident 350**（推奨）：CoreXY ＋ Z 3 本、350mm 角。本計画とほぼ同じ構成で、部品リスト・組立マニュアル・Klipper 設定例がそろっています。X/Y（A/B）に 0.9° モーターを使う構成例も多く、モーター取付寸法も NEMA17 標準なのでそのまま付きます。ただし Z は純正だと台形ネジ一体型モーターなので、カップリング接続に改造が必要です（[bom.md](bom.md) 参照）。
- **Voron 2.4 350**：ガントリーが上下する方式。より高性能ですが Z モーターが 4 本必要で、組立も難しくなります。
- **RatRig V-Core**：アルミ押し出し材中心の CoreXY。大型サイズ（400/500mm）も選べます。

### 💡 解説

- 大型プリンターで一番難しいのは「フレームの直角・平行を出すこと」と「ベッドを均一に温めること」です。実績のある設計はこれらの問題がすでに解決されているので、失敗が大幅に減ります。

## 8. 安全対策（必ず守ること）

1. **AC 100V 配線**：アース（接地）を必ず取る。端子にはカバーを付け、むき出しにしない。自信がなければ AC 部分は経験者に確認してもらう。
2. **ヒートベッドに温度ヒューズ**（120〜130℃程度）を貼り付け、ソフトウェアが暴走しても物理的に電源が切れるようにする。
3. **SSR は放熱板付きで、定格に余裕のあるもの**（ヒーター電流の 2 倍以上）を使う。偽物が多いので信頼できる店で買う。
4. **Klipper の熱暴走保護**（`verify_heater`）を無効にしない。
5. 初めのうちは **無人で印刷しない**。煙感知器を設置する。
6. 配線は可動部に引っかからないようケーブルチェーン等で固定する。

## 9. 進め方（フェーズ）

| フェーズ | 内容 | 完了の目安 |
|---|---|---|
| **0. 検討** | ベース設計（Voron Trident 350 など）を決め、部品表を確定（[bom.md](bom.md)） | 部品を発注できる状態 |
| **1. モーター単体テスト** | 制御ボード＋TMC2209＋24V でこのモーターを 1 台回し、速度を上げて脱調する速度を測る | §3 の見積もりと実測値を比較 |
| **2. フレームと動作系** | フレーム組立、XY・Z を動かす。ホットエンドなしで動作確認 | ホーミングと `Z_TILT_ADJUST` が通る |
| **3. 印刷開始** | ホットエンド・ベッド接続、PID 調整、インプットシェーパー、圧力補正（Pressure Advance） | キャリブレーションキューブがきれいに出る |
| **4. 応用（任意）** | エンコーダーによる脱調検出、48V 化による高速化など | — |

### 💡 解説

- **フェーズ 1 が重要**：§3 の数値は計算上の目安なので、全部組み立てる前に 1 台だけで実測しておくと、「組んだら思ったより遅かった」という失敗を防げます。
- **PID 調整**：ヒーターの温度を目標値でぴったり安定させるための調整です（Klipper の `PID_CALIBRATE` コマンドで自動）。
- **Pressure Advance**：ノズル内の圧力の遅れを補正し、角がにじむのを防ぐ機能です。
